# R4 — Silent float64 coercion in embed/preprocess paths

> x86→Arm/Graviton migration template · kind: `static` · confidence: high · expected gain (estimate): 1.3–2×

## Anti-pattern

numpy array constructors (np.array / zeros / ones / empty / full / linspace) called without an explicit dtype default to float64 for float inputs. Embedding and preprocessing pipelines silently double memory traffic and halve SIMD lane width on aarch64, then usually cast to float32 at the model boundary anyway.

## Before → after

```python
emb = np.zeros((n, dim))                 # float64 by default
```

```python
emb = np.zeros((n, dim), dtype=np.float32)
```

## Fix

Pin dtype=np.float32 at each flagged constructor call site (patch lists every file:line); keep an explicit cast only at the model boundary.
