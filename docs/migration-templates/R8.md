# R8 — pip fell back to sdist build for a performance-critical package

> x86→Arm/Graviton migration template · kind: `probe` · confidence: medium · expected gain (estimate): 1.2–3×

## Anti-pattern

The install log shows a perf-critical package (numpy, pillow, tokenizers, onnxruntime, ...) downloaded as a .tar.gz sdist and compiled in-place instead of installing a manylinux aarch64 wheel — source builds routinely miss the tuned NEON/OpenBLAS configuration the official wheels ship.

## Before → after

```bash
pip install pillow==9.0.0                # no aarch64 wheel -> compiles from sdist
```

```bash
pip install --only-binary=:all: "pillow>=10.2"   # fails loudly instead of building
```

## Fix

Pin the package to a version that publishes manylinux_*_aarch64 wheels (or a newer Python/base image that has them) and enforce --only-binary=:all: for the watchlist in CI.
