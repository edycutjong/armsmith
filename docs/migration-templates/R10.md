# R10 — llama.cpp/ggml built without KleidiAI (GGML_CPU_KLEIDIAI=OFF)

> x86→Arm/Graviton migration template · kind: `probe` · confidence: high · expected gain (estimate): 1.2–2×

## Anti-pattern

The CMake cache of a ggml/llama.cpp build shows GGML_CPU_KLEIDIAI absent or OFF. KleidiAI microkernels use dotprod/i8mm/SVE/SME and are selected at runtime per detected CPU capability — leaving the flag off forfeits them (flag surface verified in crawl/clean/sdk_llamacpp.md).

## Fix

Rebuild with -DGGML_CPU_KLEIDIAI=ON (A/B both builds through the gate); on SME-capable hosts additionally sweep the GGML_KLEIDIAI_SME env var (unset / 0 / >0); on macOS pin --device none for any CPU claim because Metal outranks CPU.
