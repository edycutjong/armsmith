# R7 — ONNX Runtime session left on defaults (threads / graph optimization)

> x86→Arm/Graviton migration template · kind: `probe` · confidence: high · expected gain (estimate): 1.2–1.8×

## Anti-pattern

SessionOptions with intra_op_num_threads=0 lets every worker grab all cores (oversubscription once workers > 1), and a graph optimization level below ORT_ENABLE_ALL leaves fusions and layout optimizations off — both are silent defaults that cost latency on aarch64 CPU inference.

## Before → after

```python
sess = ort.InferenceSession(model)       # every session option left on defaults
```

```python
so = ort.SessionOptions()
so.intra_op_num_threads = 2              # floor(nproc / workers)
so.inter_op_num_threads = 1
so.graph_optimization_level = ort.GraphOptimizationLevel.ORT_ENABLE_ALL
sess = ort.InferenceSession(model, so)
```

## Fix

Emit a session-options patch: intra_op_num_threads = floor(nproc/workers), inter_op_num_threads = 1, graph_optimization_level = ORT_ENABLE_ALL (default CPU EP; ACL EP is community-maintained and mention-only).
